# NexusHome Technologies

A proposed smart-home management application that brings lighting, security cameras, thermostats, and other connected devices into one dashboard.

Project status: This repository contains project documentation. It does not include a working application or installer.

## Overview

Managing a smart home often means switching between separate apps to adjust lights, check cameras, or change the temperature. NexusHome Technologies proposes one place to view and manage those everyday tasks. Its goal is to make connected devices easier to find, understand, and control.

## Planned features

- Lighting: View connected lights and adjust their settings from one place.
- Security cameras: Access views from compatible, authorized cameras.
- Thermostats: View and change temperature settings on supported devices.
- Device organization: Group connected devices by room or purpose.
- Central dashboard: Reach common home controls without switching between device-specific apps.

These features describe the intended application, not functions verified in a released product.

## Usage

The planned experience is to open the dashboard, connect compatible devices, organize them by room, and select a device to view or change its available controls. For examples covering lighting, cameras, and thermostats, see the [User Guide](https://github.com/mbhsiddiqui/VCC_3/wiki/User-Guide).
